bases
Conversões rápidas

      
BaseAgrupar bitsEx.: 357
Hexade 4 em 40x165
Octalde 3 em 3545₈
Binário—1 0110 0101

      
Fração → binário: multiplique por 2 e pegue a parte inteira (0,375 → .011).

    
inteiros
Faixas com n bits

      
RepresentaçãoFaixa
Sem sinal0 … 2ⁿ − 1
Complemento de 2−2ⁿ⁻¹ … 2ⁿ⁻¹ − 1
Sinal-magnitude / C1−(2ⁿ⁻¹ − 1) … 2ⁿ⁻¹ − 1 (dois zeros)
Enviesada (viés 2ⁿ⁻¹−1)valor = armazenado − viés

      
Overflow com sinal: somar dois de mesmo sinal e o resultado trocar de sinal. Unsigned: carry-out do MSB.

    
ieee-754
Precisão simples (32 bits)

      
1 bit sinal | 8 bits expoente (viés 127) | 23 bits fração

      
Valor = (−1)ˢ × 1,fração × 2exp − 127

      
ExpoenteFraçãoSignifica
00±0
0≠0subnormal
2550±∞
255≠0NaN

      
Dupla: 11 bits de expoente (viés 1023) e 52 de fração.

    
risc-v
Formatos RV32I


R  funct7 | rs2 | rs1 | f3 | rd       | opcode
I  imm[11:0]    | rs1 | f3 | rd       | opcode
S  imm[11:5]| rs2 | rs1 | f3 | imm[4:0] | opcode

      
Instr.Opcodef3f7
add01100110000000000
sub01100110000100000
addi0010011000—
lw0000011010—
sw0100011010—

      
Imediato de 12 bits em C2: −2048 … 2047. Toda instrução tem 4 bytes: PC ← PC + 4.

    
registradores
Quem é quem

      
x0zero: sempre 0, escritas ignoradas
x1ra: endereço de retorno
x2sp: ponteiro de pilha
x10–x11a0–a1: argumentos e retorno
PCendereço da instrução atual (fora de x0–x31)
IRguarda a instrução buscada

      
RISC-V é little-endian: o byte menos significativo fica no menor endereço.

    
gcc
Compilação passo a passo


gcc -E prog.c -o prog.i   # pré-processamento
gcc -S prog.i -o prog.s   # compilação → assembly
gcc -c prog.s -o prog.o   # montagem → objeto
gcc prog.o -o prog        # ligação (linker)

      
"undefined reference" = erro do linker. #define é resolvido no pré-processamento.

    
memória
Onde cada variável mora

      
TEXTcódigo das funções
RODATAconst global/static, literais de string
DATAglobal/static com valor inicial ≠ 0
BSSglobal/static sem valor inicial ou = 0
HEAPmalloc até free
STACKlocais automáticas, parâmetros, ponteiros locais

      
const sozinho não define a região: const local fica na pilha.

    
desempenho
Fórmulas

      
Tempo de CPU = nº instruções × CPI ÷ frequência

      
Amdahl: speedup = 1 ÷ ((1 − f) + f ÷ s)

      
Ex.: 80% acelerado 4× → 1 ÷ (0,2 + 0,2) = 2,5×

      
Imagem: largura × altura × bytes/pixel · Áudio: taxa × bytes × canais × segundos

    
pegadinhas
O que derruba na prova

      
  • lb estende o sinal, lbu estende com zeros.
  • «sw rs2, imm(rs1)»: o registrador fonte é o rs2.
  • static int x = 0; local → BSS, inicializa uma única vez.
  • strlen("Ação") em UTF-8 = 6 bytes.
  • 0,1 não tem representação binária exata.
  • Retornar endereço de vetor local = ponteiro pendente.
